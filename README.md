# HamburgueriaZ 🍔

Projeto desenvolvido na disciplina de Desenvolvimento Mobile.

## Tecnologias utilizadas
- Java
- Android Studio
- XML
- Android SDK

## Funcionalidades
- Inserção do nome do cliente
- Escolha de adicionais
- Controle de quantidade
- Cálculo automático do pedido
- Envio de pedido utilizando Intent

## Objetivo
Praticar conceitos de desenvolvimento Android utilizando Java.
